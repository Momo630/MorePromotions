# Unciv-mod-example

An example mod for Unciv, that adds one new Civilization.

For information on how to build and use mods, please refer to [the setup instructions](https://yairm210.github.io/Unciv/Modders/Making-a-new-Civilization/)

Air Mobile I, II, and III set paradrop limits of 2, 4, and 7 tiles; Unciv uses the highest matching limit. Paradrops start from friendly land and target land tiles. Martyr's culture action consumes the unit automatically.
